# Android 14 Weather App

An Android weather application developed as part of an Android development course, created to practice mobile application development using Android Studio and the Android 14 platform.

The project focuses on building an Android application capable of retrieving and presenting weather information through a user-friendly mobile interface.

## About the Project

This project was developed as a learning experience during my early studies in Android development.

The main goal was to understand the fundamentals of building an Android application, including application structure, user interface development, interaction with external data, and the Android development workflow.

It allowed me to put theoretical concepts into practice while becoming familiar with the Android Studio development environment and the Android 14 ecosystem.

## Key Features

* Weather information displayed through a mobile interface
* Integration with weather data
* User interaction with the application
* Android 14 development environment
* Responsive mobile UI
* Data retrieval and presentation

## Technologies

* Android
* Android Studio
* Android 14
* Kotlin
* REST API
* Git & GitHub

## What I Learned

Through this project, I gained practical experience with:

* Handling and presenting data in a mobile interface
